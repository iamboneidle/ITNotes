# 1. Сколько портов
В Linux, как и во всех операционных системах, использующих стек протоколов TCP/IP, общее количество портов составляет 65536 (от **0** до **65535**). Это ограничение продиктовано размером поля заголовка TCP/UDP, которое составляет 16 бит ($2^{16} = 65536$).

# 2. Диапазоны
## 2.1. Системные или "Хорошо известные" порты
- **Диапазон:** **0 – 1023**
- **Особенности:** Зарезервированы для стандартных сервисов и критических системных процессов.
- **Linux-специфика:** В Linux (и других Unix-подобных системах) только процессы с правами **root** (или имеющие специальную привилегию `CAP_NET_BIND_SERVICE`) могут «слушать» эти порты.
- **Примеры:**
    - `22` (SSH)
    - `80` (HTTP)
    - `443` (HTTPS)
    - `53` (DNS)
## 2.2. Зарегистрированные порты
- **Диапазон:** **1024 – 49151**
- **Особенности:** Используются для приложений и сервисов, которые не являются критически важными для работы ОС, но зарегистрированы в IANA (Internet Assigned Numbers Authority).
- **Linux-специфика:** Любой пользователь может запустить процесс на этих портах.
- **Примеры:**
    - `3306` (MySQL)
    - `5432` (PostgreSQL)
    - `6379` (Redis)
    - `8080` (Альтернативный HTTP/Tomcat)
## 2.3. Динамические или Эфемерные порты
- **Диапазон (по стандарту IANA):** **49152 – 65535**
- **Особенности:** Эти порты не закреплены за конкретными сервисами. Система выделяет их автоматически (динамически), когда клиентское приложение (например, ваш браузер) открывает исходящее соединение к серверу.
- **Linux-специфика:** По умолчанию в большинстве дистрибутивов Linux диапазон эфемерных портов шире, чем рекомендует IANA: обычно это **32768 – 60999**.
## 2.4. Как проверить и изменить диапазоны в Linux
Если вам нужно узнать, какой именно диапазон эфемерных портов настроен на вашем сервере прямо сейчас, используйте команду:
```shell
cat /proc/sys/net/ipv4/ip_local_port_range
```
Или через `sysctl`:
```shell
sysctl net.ipv4.ip_local_port_range
```
> [!note] 
> Формально порт `0` существует, но он зарезервирован. В программировании сетевых сокетов попытка бинда (bind) на порт `0` — это сигнал системе: «выдели мне любой свободный порт из динамического диапазона».
